# App Button

A reusable Flutter button supporting Material and Cupertino platforms.

## Features

- Primary, secondary, outline, ghost and danger variants
- Loading state
- Leading icon
- Trailing icon
- Custom colors
- Custom border radius
- Expand or fixed-width layout
- Material support
- Cupertino support
- Disabled state
- Custom elevation

## Installation

Copy `app_button.dart` into your Flutter project.

## Basic Usage

```dart
AppButton(
  label: 'Continue',
  onPressed: () {},
)
